# Myke Photo Organizer

A Windows desktop app for organizing photos.

## Download

**[Download the latest version](https://github.com/MykePalma/MykePhotoOrganizer-releases/releases/latest/download/MykePhotoOrganizer-win-x64.exe)** (66 MB, 64-bit Windows)

There is nothing to install and you don't need .NET. Just run the file.

## Windows security warning

The app isn't code-signed yet, so Windows may show "Windows protected your PC". To run it anyway, click **More info**, then **Run anyway**.

Each [release](https://github.com/MykePalma/MykePhotoOrganizer-releases/releases) lists a SHA256 checksum, so you can check your download:

```powershell
Get-FileHash .\MykePhotoOrganizer-win-x64.exe -Algorithm SHA256
```

This repository only hosts downloads. The source code is not public.
